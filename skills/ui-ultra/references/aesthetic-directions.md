# 知名品牌先例与全景行业自适应手册

> **核心理念**：UI Ultra 的底层是**秩序、亲密性、排版节奏与可读性**；表层则是**高度开放的风格转换器**。
> 当用户没有指定方向时，默认采用 **01 · 知性人文编辑调（Editorial Minimal）**；一旦涉及具体行业（食品、科技、艺术、哲学、服装、服务、教育、金融、电商、媒体、出行、公共服务）或点名品牌风格，立即调用下方的**品牌先例配方**与**行业矩阵**。

## 第一部分：12 大殿堂级品牌设计先例（Brand Precedents）

每个先例提炼出可直接转化为 CSS Token 与布局代码的 6 个工程维度：**核心哲学 · 字体配方 · 色彩与表面 · 几何与深度 · 动效节奏 · 签名细节（Signature Moves）**。

### 01 · Kinfolk / Stripe Press / The New Yorker —— 知性书卷与温暖极简（默认基准）
> 像一本装帧考究的精装思想手记：温暖、安静、克制，永远不抢内容的风头。

- **适用**：AI 思考/写作工具、知识库、哲学人文、学术出版、文档站、个人数字花园
- **字体**：高可读人文衬线标题（`Newsreader` / `Source Serif 4` / `Noto Serif SC`）× 干净无衬线正文（`Inter` / `Instrument Sans` / `PingFang SC`）× 代码 `JetBrains Mono`
- **色彩**：
  - 画布：暖米白 `#faf9f5` · 卡片表面 `#ffffff` · 下沉批注区 `#f0eee6`
  - 文字：暖近黑 `#141413` · 次要 `#5e5d59` · 辅助 `#87867f`
  - 强调：赤陶 `#c96442`（大字/图形/下划线）· **实心按钮加深为 `#b4553a`**（保证白字对比度 ≥ 4.9:1）· 浅底 `#f5e6dd`
  - 暗色：深暖灰 `#181715` · 表面 `#21201e` · 强调提亮为 `#d97757`
- **几何与深度**：圆角 `8–14px`；以 `1px` 暖灰细线分割代替重阴影，卡片仅带极轻环境影
- **签名细节**：衬线大标题与无衬线正文的知性碰撞；边栏批注卡片与引文页码溯源；大量温暖米白留白

### 02 · Apple —— 极致减法、光学精密与 Bento 叙事
> 界面退后，让产品微距摄影与核心参数成为唯一焦点。

- **适用**：消费电子、智能硬件、旗舰科技产品落地页、Mac/iOS 级原生质感应用
- **字体**：系统级几何/新怪诞无衬线（`SF Pro Display` / `Inter` / `PingFang SC`）；大标题字重 `600–700`、紧凑负字距 `-0.025em ~ -0.035em`；中文标题不收负字距但行高收紧至 `1.12`
- **色彩**：
  - 亮色：纯净白 `#ffffff` 画布 × 浅冷灰 Bento 容器 `#f5f5f7` · 文字 `#1d1d1f` · 次要 `#6e6e73`
  - 暗色：纯黑 `#000000` 画布 × 深钛灰容器 `#1d1d1f` · 文字 `#f5f5f7` · 次要 `#86868b`
  - 强调：克制的光学蓝 `#0071e3`（暗色 `#2997ff`），仅用于购买按钮与关键链接
- **几何与深度**：大圆角 Bento 容器 `20–28px`，胶囊按钮 `9999px`；粘性顶栏采用高饱和还原毛玻璃 `backdrop-filter: saturate(180%) blur(20px)`
- **动效**：光学阻尼曲线 `cubic-bezier(0.22, 1, 0.36, 1)`，时长 `300–450ms`
- **签名细节**：大小交错的 **Bento 特性总结网格**（巨幅参数数字 + 一句话定性 + 局部硬件特写）；全宽居中大标题配双胶囊行动点

### 03 · Nike —— 竞技张力、浓缩粗体海报与动态网格
> 速度感、肌肉感與街头文化冲击力 —— 字体像海报一样咆哮，网格像跑道一样利落。

- **适用**：运动装备、潮流服饰、球鞋发售（SNKRS）、健身竞技应用、街头文化节、电竞潮牌
- **字体**：超粗浓缩无衬线标题（`Futura Condensed ExtraBold` / `Oswald` / `Anton` / `Impact` + 中文高字重黑体 `700–900`），西文全大写、行高极紧 `0.92–1.05`
- **色彩**：
  - 高对比黑白基底：纯白 `#ffffff`、冷浅灰 `#f5f5f5`、沥青黑 `#111111`
  - 竞技点色：荧光伏特黄 `#ceff00`（**必须配纯黑字 `#111`**）、炽热红外线 `#ff3b1d`、赛道橙 `#fa5400`
- **几何与深度**：硬朗利落，卡片圆角 `0–4px`，行动按钮采用全圆角胶囊 `9999px`（形成“方画布 + 圆胶囊”的视觉张力）；零阴影，靠色块与实线切分
- **动效**：干脆利落 `150–220ms`，快速滑入与尺码选中瞬态反馈
- **签名细节**：突破常规比例的巨型海报字阶（`clamp(3.2rem, 8vw, 6.5rem)`）；全出血运动抓拍图；直观的尺码矩阵网格（Size Grid）与发售倒计时

### 04 · McDonald's (Turner Duckworth 体系) —— 欢快波普与食欲直觉
> 温暖、饱满、零认知负担 —— 色彩直接唤醒多巴胺与食欲，3 秒内完成点单决策。

- **适用**：连锁餐饮（QSR）、汉堡/披萨/炸鸡、奶茶果饮、烘焙甜品、生鲜超市、休闲零食消费品
- **字体**：圆润饱满的几何无衬线（`Fredoka` / `Plus Jakarta Sans` / `Nunito` / `HarmonyOS Sans SC`），字重偏厚（`600–700`），亲切易读
- **色彩**：
  - 画布：热腾腾的暖奶油白 `#fffdf7` · 套餐卡表面 `#ffffff` · 柔和暖杏底 `#fff4d6`
  - 品牌双主色：拱门金黄 `#ffbc0d`（**注意：金黄底色上白字对比度仅 1.7:1，按钮文字必须用深烘焙棕 `#27251f`，对比度达 10.8:1！**）× 番茄红 `#db0007`（配白字）
  - 辅助色：生菜翠绿 `#264f36`（健康/素食标签）
- **几何与深度**：饱满大圆角 `16–24px`，按钮与价格标签全胶囊 `9999px`；柔和暖色系扩散阴影或轻快 2px 描边
- **动效**：富有弹性的微交互 `cubic-bezier(0.34, 1.4, 0.64, 1)`，点击「+ 加入餐盘」时数字徽标轻快跳动
- **签名细节**：食物微距去底大图允许轻微破框（溢出卡片顶部 8–12px）；一目了然的卡路里/辣度/份量胶囊标签；底部常驻的暖金色结算横幅

### 05 · Cartier / Hermès —— 高定奢华、展柜剧场与古典衬线
> 浏览器里的丝绒珠宝展柜：克制、对称、矜贵，时间在这里变慢。

- **适用**：高级珠宝腕表、高定时装、奢华香氛美妆、私人银行/家族办公室、高端艺术拍卖、买手画廊
- **字体**：高对比度古典/现代过渡衬线（`Cormorant Garamond` / `Playfair Display` / `Bodoni Moda` / `Noto Serif SC`），字重偏轻至中等（`400–500`）；分类眉标使用极小号全大写宽字距无衬线（`font-size: 11px; letter-spacing: 0.18em`）
- **色彩**：
  - 双生画布：深邃丝绒黑 `#0c0b0a` 或 羊皮香槟白 `#fcfaf5`
  - 强调：香槟金 `#b89758` / 卡地亚深酒红 `#6e1414` / 爱马仕焦橙 `#d65a28`
  - 分隔线：极细金属感游丝线 `1px solid rgba(184, 151, 88, 0.28)`
- **几何与深度**：**严格 `0px` 直角**（按钮、图片、输入框全直角）；零投影，靠大幅留白与 1px 细框塑造秩序
- **动效**：从容缓慢的剧场级过渡 `450–650ms cubic-bezier(0.16, 1, 0.3, 1)`，图片悬停仅做极轻微的 `scale(1.02)` 缓慢推镜
- **签名细节**：中轴对称或画册级双栏构图；按钮采用 `1px` 细边框 + 悬停平滑填满底色；不直接暴露喧闹的促销价，代之以「探索作品 / 预约私人沙龙鉴赏」

### 06 · Aesop / Kinfolk —— 建筑感药房网格与大地肌理
> 诚实、智性、贴近自然材质 —— 像走进一间摆满琥珀色玻璃瓶与纸质处方笺的静谧空间。

- **适用**：护肤个护、家居香氛、精品茶叶/咖啡豆、独立书店、室内建筑设计、有机生活方式品牌
- **字体**：文学感衬线标题（`Optima` / `Newsreader` / `Lora` / `Noto Serif SC`）× 冷静理性的无衬线说明与配方表
- **色彩**：

- **几何与深度**：`0–2px` 微圆角；完全平面化，使用水平横线（`1px solid #d5cebe`）构建如药房抽屉般的严整信息表格
- **签名细节**：产品卡片下方附带药典式属性横条（`肤质 / 关键成分 / 香调`）；左栏固定分类导言 + 右栏横向滑动的陈列架

### 07 · Linear / Raycast —— 暗色工程精密与键盘优先
> 精密仪器般的现代软件工艺，细节藏在 1px 的微光倒角与毫秒级的键盘响应里。

- **适用**：开发者工具、AI 编程/Agent 平台、生产力软件、云原生基础设施、Cybersecurity
- **字体**：`Inter Variable`（启用 `cv01, ss03`）或 `Geist` × 等宽 `Geist Mono` / `JetBrains Mono`；标题采用标志性的 `510–550` 中等字重 + `-0.02em` 字距
- **色彩**：
  - 暗色主画布 `#08090a` → 一级容器 `#101113` → 抬升面板 `#18191c`
  - 文字 `#f2f3f5` · 次要 `#8a8f98` · 辅助 `#5c6068`
  - 强调：克制的冷光色（线性靛蓝 `#5e6ad2` 或 终端翠绿 `#3ecfb4`）
  - 边框：`rgba(255, 255, 255, 0.08)` + 卡片顶部 1px 内高光 `inset 0 1px 0 rgba(255, 255, 255, 0.06)`
- **几何与深度**：圆角 `6–10px`；极弱的顶部径向环境光晕（不刺眼、不廉价）
- **签名细节**：随处可见的 `<kbd>⌘ K</kbd>` 快捷键提示；命令面板（Command Palette）；状态流转小圆点与毫秒级响应

## 第三部分：如何从用户的参考图或一句话中提取风格（Adaptation Rules）

当用户说“参考某某品牌”、“按照这张图的感觉做”或“做一个卖咖啡的网站”时，按以下 3 步完成转译：

1. **锁死 UI Ultra 底层骨架（不变）**：
   保留语义 Token 命名（`--bg`, `--surface`, `--text`, `--accent`, `--radius-*`, `--space-*`）、中文字体回退栈、控件继承重置、`:focus-visible` 焦点环与响应式容器。
2. **拨动 6 大风格旋钮（变形）**：
   - 确定**色温与明暗**（如：咖啡烘焙 → 暖奶油 `#fdfbf7` + 浓缩咖啡深棕 `#231b15` + 焦糖琥珀 `#b85d19`）。
   - 确定**字体性格**（如：奢品 → 高对比衬线 + 宽字距大写眉标；运动 → 浓缩粗黑斜体）。
   - 确定**几何圆角与边框**（如：艺术画廊 → `0px` 直角 + 外露 1px 黑线；少儿教育 → `20px` 圆角 + `4px` 底边物理厚度）。
3. **植入 1–2 个行业原生微件（灵魂）**：
   不要只换颜色！**不同行业必须长出不同结构的组件**：
   - 做餐饮，首屏就要有**食物规格胶囊与加购餐盘**；
   - 做奢品，就要有**画册留白与沙龙鉴赏预约**；
   - 做艺术展，就要有**外露网格与馆藏展签（`FIG. 01`）**；
   - 做 AI 写作/研发，就要有**可交互的审阅台或代码沙盒**。
