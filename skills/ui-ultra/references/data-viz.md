# 数据可视化与仪表盘

仪表盘的目标不是"看起来很多数据"，而是**让人 5 秒内知道现在好不好、哪里需要处理**。
颜色变量来自 [tokens.css](tokens.css) 的 `--chart-*`。

---

## 1. 仪表盘布局

**信息层级（从上到下、从左到右）**
1. **结论层**：3–5 个关键指标卡（KPI）。不是 8 个，不是 12 个。
2. **趋势层**：1–2 张主图表，解释 KPI 为什么变化。
3. **明细层**：表格 / 列表，可筛选、可下钻。

**规则**
- 最重要的指标放左上；同类指标放一起；全局筛选（时间范围、维度）放页面顶部右侧，并对整页生效。
- 网格：12 栏，图表卡最小宽度 4 栏（桌面）；KPI 卡等宽一行。
- 卡片之间 16–24px；卡片内边距 20–24px；同一页卡片高度按行对齐。
- 每张图表卡：标题（说明"这是什么"）+ 可选副标题（口径、时间范围）+ 图 + 可选图例/操作。
- 实时数据要标注"更新于 14:32"；口径不明的指标给 ⓘ Tooltip 解释计算方式。
- **不要为了填满网格而加图表**。一张没人看的图是噪音。

---

## 2. KPI 指标卡

```
营收（本月）                  ← --text-sm, secondary
¥ 128.4 万                    ← --text-3xl, 600, tabular-nums, --text
▲ 12.3%  较上月               ← --text-sm；涨跌用 颜色 + 箭头 + 符号，三者缺一不可
[ 迷你趋势线 sparkline ]       ← 可选，高 32–40px，无坐标轴
```

- 数字是主角：大字号 + 正文色；单位和货币符号缩小一档、用 secondary 色。
- 涨跌颜色**按业务语义**而不是按方向：成本上涨是坏事。中国股市惯例"红涨绿跌"与西方相反——面向 A 股/国内金融用户时遵循本地惯例，并始终配合 ▲▼ 符号。
- 对比基准写清楚："较上月""较去年同期""目标 80%"。
- 无数据显示 "—" 而不是 0；数据加载中用骨架，不要先显示 0 再跳变。

## 3. 选对图表

| 想表达 | 用 | 避免 |
|---|---|---|
| 随时间的趋势 | 折线图（≤ 5 条线）；面积图（单系列或堆叠总量） | 3D、过多系列的折线"意大利面" |
| 类别之间比较 | 横向条形图（类别名长/多时）、柱状图（≤ 12 类） | 饼图比较 5 个以上类别 |
| 占比 / 构成 | 单条 100% 堆叠条、环形图（≤ 5 块，最好 2–3 块） | 多个饼图并排比较 |
| 分布 | 直方图、箱线图 | 用平均值掩盖分布 |
| 两个变量关系 | 散点图 | 双 Y 轴（极易误导，必须用时两轴颜色区分并标注） |
| 单一数值对目标 | 进度条、子弹图 | 仪表盘式"汽车表盘" |
| 精确数值查询 | 表格 | 把表格硬做成图表 |

**规则**
- 柱状/条形图的数值轴**必须从 0 开始**；折线图可以不从 0 开始，但要标清刻度。
- 条形按数值排序（除非类别有天然顺序，如月份、年龄段）。
- 能直接标注就不要图例：把系列名写在线条末端，数值写在柱顶。
- 超过 6 个类别：保留前 5 个 + "其他"。

## 4. 图表配色

- **分类色**：按 `--chart-1` → `--chart-6` 顺序使用；它们同明度、错开色相，保证没有哪一类"被突出"。
- **强调一条**：要讲一个故事时，只给主角上 `--chart-1`，其余系列用 `--chart-muted`。这比 6 种颜色有力得多。
- **顺序色**（热力图、数值深浅）：同一色相从浅到深 5–7 阶，用 OKLCH 只调亮度。
- **发散色**（正负、高于/低于平均）：两个对立色相 + 中间中性灰。
- **语义色**只用于语义：红色只表示"坏/危险"，不要拿来当第 3 个分类色。
- 不要只靠颜色区分系列：折线加不同线型/端点形状，或直接标注；约 8% 男性有色觉差异（红绿最常见）。
- 暗色模式：图表色提亮、降饱和（tokens 已处理）；网格线用 `--chart-grid`，比亮色模式更弱。

---

## 5. 图表细节（去 "chart junk"）

- 网格线：仅水平、1px、`--chart-grid`；或干脆去掉，用数据标签代替。
- 坐标轴：去掉轴线，只保留刻度文字（`--text-xs`、tertiary 色、`tabular-nums`）；刻度 4–6 个，取整数（0 / 25 / 50 / 75 / 100）。
- 线宽 2px；柱宽大于柱间距；柱顶可 2–4px 圆角（底部不圆角）。
- 去掉：3D、阴影、渐变填充（面积图可用 10–20% 透明度的纯色）、边框、背景色块。
- Tooltip：显示日期 + 每个系列的值（按值排序）+ 与对比基准的差值；跟随鼠标、垂直参考线吸附到最近数据点。
- 动效：首次加载可 300–400ms 生长动画；数据更新时过渡而非重绘；尊重 `prefers-reduced-motion`。
- 图表也要有空状态（"所选时间范围内没有数据"）、加载态（骨架形状）和错误态。

---

## 6. 数字格式

- 统一用 `Intl.NumberFormat`，不要手写拼接。
- **千分位**：`1,284,000`；中文语境的大数用"万/亿"：`128.4 万`、`3.2 亿`（`Intl.NumberFormat('zh-CN', { notation: 'compact' })`）。
- 精度：同一列/同一图保持相同小数位；百分比通常 1 位小数；货币 0 或 2 位。
- 负数用真正的减号 `−` 或括号（财务），不要用连字符 `-`。
- 日期：中文 `2026年11月5日` / `11月5日 14:32`；紧凑场景 `2026-11-05`；相对时间（"3 分钟前"）超过 7 天改显示绝对日期。
- 所有数字：`font-variant-numeric: tabular-nums`，表格中右对齐。

---

## 7. 可访问性

- 每张图给一句文字结论（标题或副标题就写结论："新用户本月增长 23%，主要来自搜索渠道"）。
- SVG 图表：`role="img"` + `aria-label` 概述；复杂图表提供"查看数据表"切换。
- 图表色与背景对比 ≥ 3:1（tokens 中 `--chart-*` 已满足）；相邻分类色之间也要可分辨。
- 交互式图表支持键盘：Tab 进入后用方向键在数据点间移动并播报数值。

---

## 8. 推荐库

- **通用**：ECharts（中文生态好、功能全）、Recharts / Nivo（React）、Chart.js（轻量）。
- **定制度高**：Observable Plot（快速探索）、D3（完全控制）、visx（React + D3）。
- **shadcn/ui 项目**：shadcn Charts（基于 Recharts，直接读 CSS 变量）。
- 无论用哪个：**覆盖默认主题**——把颜色、字体、网格、Tooltip 全部接到 tokens，默认主题是"AI 味"的重要来源。
