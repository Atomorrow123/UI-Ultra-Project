# 反模式详解：去掉 "AI 味"

格式：**症状** → 为什么不好 → ✅ 替代方案

---

### 1. 无意义的紫蓝霓虹渐变 / 渐变文字
**症状**：不论什么行业都套 `bg-gradient-to-r from-purple-500 to-blue-500`，标题 `bg-clip-text text-transparent`。
**问题**：已成为 AI 生成页面的廉价标志；渐变文字可读性差、在暗色/亮色切换时容易崩。
✅ **区分廉价渐变与有意图的品牌用色**：默认用纯色画布 + 单一强调色；若为餐饮快消（McDonald's 金黄/番茄红）、运动潮流（Nike 伏特黄）可用干脆的高饱和品牌平涂色块；若为金融企服（Stripe）可用受控的同色系柔和光感背景。

### 2. 到处都是毛玻璃
**症状**：卡片、按钮、弹窗全部 `backdrop-blur bg-white/10`。
**问题**：性能开销大，对比度不可控，层级混乱。
✅ 只用于"浮在内容之上且下方内容会滚动"的元素：sticky 导航、常驻迷你播放器、浮动工具栏。

### 3. "三张图标卡片" 套路
**症状**：居中 H2 "Why choose us" + 三张等宽卡片，每张一个圆形渐变图标 + 标题 + 两行描述。
**问题**：零信息密度，用户一眼跳过。
✅ 用真实产品微件/行业专属组件展示功能（餐饮放规格点单卡、运动放尺码矩阵、写作放批注对照）；采用不等大的 Bento 网格、外露瑞士网格或左右交替图文行。

### 4. Emoji 当图标
**症状**：🚀 快速 ✨ 智能 🔒 安全。
**问题**：跨平台渲染不一致，风格廉价，与品牌无关。
✅ 统一图标库（Lucide / Phosphor），统一线宽与尺寸；或使用博物馆展签/工业风的等宽序号（`01 / 02`、`FIG. 01`）。

### 5. 圆角与阴影与行业性格脱节
**症状**：不管做奢侈品还是做开发者工具，每个元素都无脑 `rounded-3xl shadow-2xl`。
**问题**：一切都在"漂浮"，既没有层级，也毁掉了行业该有的触感。
✅ 圆角与深度必须匹配行业先例：高定奢品/艺术策展用 `0px` 直角 + 零阴影 + `1px` 细线；科技/企服用 `8–12px` + 分层微影；餐饮/少儿/游戏化教育可用 `16–24px` 大圆角或 `0 4px 0` 物理厚度底边。

### 6. 无逻辑的彩虹配色
**症状**：同一组功能卡片，每张卡片换一个毫无业务含义的鲜艳颜色。
**问题**：颜色失去语义，造成视觉噪音。
✅ 中性色构建结构，强调色服务于品牌与行动锚点；数据可视化需多色区分时，使用同明度、错开色相的 `--chart-1 ~ 6`。

### 7. 空洞文案与虚假数据
**症状**："Unlock the power of AI"、"释放无限可能"、"10x faster"、"Trusted by 10,000+ teams"（凭空编造）。
**问题**：读者立即失去信任。
✅ 写具体的事实与场景："3 秒内把 PDF 转成可编辑表格"。没有真实数据就不写数据，用占位符明确标注 `[待补充：用户数]`。

### 8. 滚动动画泛滥
**症状**：每个区块进入视口都 fade-up。
**问题**：拖慢阅读，像模板站。
✅ 最多一两处有叙事意义的动效（如产品演示随滚动展开）；其余内容直接展示。

### 9. 纯黑纯白 / 过淡的灰
**症状**：`#000` 文字在 `#fff` 背景；次要文字 `#aaa`。
**问题**：前者刺眼，后者对比度不达标。
✅ 近黑 `#141413` / 米白 `#faf9f5`；次要文字对比度 ≥ 4.5:1（亮底上大约 `#5e5d59` 或更深）。

### 10. 一切居中
**症状**：标题、段落、表单、列表全部 `text-center`。
**问题**：长文本居中难以阅读，缺乏对齐线，显得业余。
✅ 默认左对齐；仅短标题、空状态、单一 CTA 区块可居中。

### 11. 魔法数字
**症状**：`padding: 13px`、`margin-top: 27px`、`font-size: 15.5px`。
**问题**：节奏感崩坏，难以维护。
✅ 全部来自 token 阶梯。

### 12. 去掉焦点环
**症状**：`*:focus { outline: none; }`。
**问题**：键盘用户无法使用，可访问性违规。
✅ `:focus-visible` 2px 强调色描边 + 2px offset；仅鼠标点击时不显示。

### 13. Placeholder 当标签
**症状**：输入框只有灰色占位提示，没有标签。
**问题**：一输入提示就消失，用户忘了这一栏是什么；对比度通常也不达标。
✅ 上方常驻标签，placeholder 只放示例值。

### 14. 按钮文案模糊
**症状**："提交"、"确定"、"OK"、"Click here"。
✅ 动词 + 宾语："发送邀请"、"导出 CSV"、"删除 3 个文件"。

### 15. 过度装饰的 Hero
**症状**：巨大渐变 blob、漂浮 3D 球体、粒子背景，但没说清楚产品是什么。
✅ 5 秒测试：用户看 Hero 5 秒后能否说出"这是什么、给谁用、下一步做什么"。用真实产品画面代替抽象装饰。

### 16. 图标与文字未对齐
**症状**：图标比文字高 1–2px，或大小不一。
✅ `display: inline-flex; align-items: center;`，图标尺寸与行高匹配（14px 文字配 16px 图标），必要时做 1px 光学修正。

### 17. 加载闪烁与布局抖动
**症状**：数据回来后内容跳动；spinner 一闪而过。
✅ 骨架屏占位并保持尺寸；图片设置 `width/height` 或 `aspect-ratio`；加载 < 300ms 不显示 loading。

### 18. 控件与中英混排字体回退失真
**症状**：按钮/输入框退化为系统默认 `Arial`；等宽标签或表格列里的汉字变成粗糙的点阵 `SimSun`（宋体）；部分字重缺失导致伪粗体。
**问题**：表单控件默认不继承 `body` 字体；`--font-mono` 未配置中文无衬线回退；Webfont 漏引了页面用到的字重。
✅ 全局重置加 `button, input, select, textarea { font: inherit; color: inherit; }`；`--font-mono` 在 `monospace` 前补齐中文无衬线回退；含中文的数字列用 `--font-body` + `tabular-nums`。

### 19. 定高胶囊 / 标签被挤压折行溢出
**症状**：徽标（`.badge`）、快捷键（`<kbd>`）或卡片顶栏在 Flex 容器中被横向挤压，末尾文字折成两行并上下冲出胶囊背景边框。
**问题**：组件写死了 `height` 且继承了正文高行高，同时缺少 `white-space: nowrap`、`flex-shrink: 0` 与父容器 `flex-wrap: wrap`。
✅ 胶囊/标签用 `min-height` + `line-height: 1.2–1.35` + `white-space: nowrap` + `flex-shrink: 0`；承载徽标的 Flex 行加 `flex-wrap: wrap` 与适度 `gap`。


### 20. 默认主题直出
**症状**：图表是 ECharts / Chart.js 默认配色，组件是 shadcn/Ant Design 默认的蓝色与圆角，Tailwind 默认 `blue-500` / `gray-*`。
**问题**：一眼"模板感"，与品牌毫无关系；多个库各自的默认值还会互相打架（三种蓝、三种圆角）。
✅ 所有第三方组件与图表的颜色、字体、圆角、阴影都接到同一套 token（见 tokens.css 末尾的 Tailwind / shadcn 映射、data-viz.md §8）。

### 21. 仪表盘指标堆砌
**症状**：首屏 8–12 张 KPI 卡 + 6 种图表，每张都带彩色图标和 "+12.5%"。
**问题**：没有主次，用户找不到"现在到底好不好"；虚构的涨幅更会摧毁信任。
✅ 3–5 个关键指标 + 1–2 张解释趋势的主图 + 明细表；每个数字都有对比基准与口径（见 data-viz.md）。

### 22. 用 div 做按钮 / 链接
**症状**：`<div onclick>`、`<span class="btn">`、`<a href="#" onclick>`。
**问题**：键盘无法聚焦与触发，读屏不知道它能点，右键/新标签页失效。
✅ 操作用 `<button type="button">`，跳转用 `<a href>`；样式可以一样，元素不能错。

### 23. 确认弹窗泛滥
**症状**：每次删除、归档、移动都弹"确定要执行此操作吗？"。
**问题**：用户形成肌肉记忆直接点"确定"，真正危险的操作反而失去保护。
✅ 可撤销的操作直接执行 + "撤销" Toast；只对**不可逆且影响大**的操作确认，并在弹窗里复述后果。

### 24. 占位文案与英文残留
**症状**：Lorem ipsum、"这是一段描述文字"、中文产品里混着 "Get started" "Learn more" "Dashboard"。
**问题**：无法判断排版在真实内容下是否成立（中文长度、换行、截断），也显得未完成。
✅ 用像真的中文内容填充（见 ux-writing.md §7）；界面语言统一，专有名词除外。

### 25. 字号与字重泛滥
**症状**：一页里出现 11、13、15、17、18、22px 等七八种字号，400/500/600/700/800 全用上。
**问题**：层级反而模糊，像拼贴。
✅ 只用阶梯中的 5–6 档字号、2–3 档字重；层级拉不开时先调间距和颜色，而不是再加一个字号。

### 26. 只在一种情况下检查
**症状**：只在 1440px 亮色模式、短文案、满数据下看过效果。
**问题**：上线后在手机、暗色、长用户名、空数据、200% 缩放、Windows 高对比度下破版。
✅ 交付前跑一遍"压力测试"：375px · 暗色 · 超长文本 · 空数据 · 错误态 · 200% 缩放 · 键盘走查（见 SKILL.md §6）。

### 27. 一套“性冷淡模板”通吃所有行业
**症状**：不管用户要做餐饮点单、街头潮牌、少儿教育还是高定珠宝，全做成一模一样的灰白底 SaaS 落地页，只把文字改掉。
**问题**：缺乏行业灵魂与情绪感染力——用性冷淡灰白卖汉堡会让人毫无食欲，用圆润卡通按钮卖高定腕表会瞬间拉低品牌溢价。
✅ **守住底层秩序，放开表层风格**：保留 UI Ultra 的排版节奏与语义 Token 底座，按 [aesthetic-directions.md](aesthetic-directions.md) 调谐色温、字阶张力、圆角几何与行业专属微件（见 [style-samples.md](style-samples.md)）。
